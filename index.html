✦ Nebular

bowed / plucked strings
Note
Melody strings · F1–D5 · click a note to select it: Pluck switches that note between bow and pluck (soft plucked notes are palm-muted), Fine tunes velocity 5–115. Line picks the Bend (green, semitones) or Vel (amber, bottom = quiet · top = loud) automation shown over the note — the line is locked until you switch Edit on, so normal move / extend / delete gestures always work otherwise. With Edit on: click the line to add a point, drag points, double-click a point to remove it, Clear line wipes the shown line.

❖ Spectrachord

dual-oscillator chords
Note
Dual notes · D1–D7 · each note splits in two: top half = osc 1, bottom half = osc 2. Drag a half up/down to retune it, drag its end right to hold it longer, drag the body sideways to move both (shared start).

● Nexdrum

pitched kicks · snares · cymbals
Hit
Drums · 7 kicks (E2–A♯2) · 7 snares (B2–F3) · 7 cymbals (F♯3–C4). All pitches from the real kit. Tap a hit to select it and set its options below; tap it again to remove it. Velocity picks the strike zone: cymbals bell / bow / edge, snare edge / middle / center, kick heel / middle / toe.
Click empty cell = add note · drag right = longer note · click a note = select it, then use Len −/+ below the grid · double-click note = delete · right-click = soft/normal/accent. Touch: one finger draws, two fingers scroll the grid.
